## Before you work on a feature

1. Run `just --list --list-submodules` to find the available commands.
2. Read `.moon/workspace.yml` to find every project and its directory.
3. Read the `moon.yml` file of each project you touch.

A `moon.yml` file gives the language, the layer, the tags and the dependencies
of one project. Those files describe the layout of this repository.

## The code is the source of truth

Read the code to learn what this project does.

Do not write a markdown file to describe the code. Do not add a design note, an
architecture note, a plan file or a summary file. If you must explain something,
write it in the chat.
